# Unit Converter

A modern and user-friendly **Unit Converter Android application** built with **Kotlin and Jetpack Compose**. The app provides a clean interface for converting different types of measurements with a simple and intuitive user experience.

## ✨ Features

* 🔄 Convert different units easily
* 📏 Length unit conversion
* ⚖️ Weight unit conversion
* 🌡️ Temperature conversion
* 🧭 Simple navigation between converter screens
* 🎨 Modern UI built with Jetpack Compose
* 🌊 Custom splash screen with animation
* 📱 Responsive Android interface
* 🧩 Reusable and organized Compose components
* 🎯 Input validation for conversion values

## 🛠️ Technologies Used

* **Kotlin**
* **Jetpack Compose**
* **Android SDK**
* **Material Design**
* **Gradle Kotlin DSL**
* **Android Navigation**

## 📱 App Overview

Unit Converter is designed to make everyday unit conversions quick and easy.

The application provides dedicated conversion screens and a straightforward interface so users can enter a value, select the required units, and view the converted result.

## 🚀 Getting Started

### Prerequisites

Before running the project, make sure you have:

* Android Studio installed
* Android SDK configured
* Kotlin support enabled
* An Android emulator or physical Android device

### Installation

1. Clone the repository:

```bash
git clone https://github.com/areejfatima313/Unit-Converter.git
```

2. Open the project in **Android Studio**.

3. Allow Gradle to sync and download the required dependencies.

4. Connect an Android device or start an emulator.

5. Run the application from Android Studio.
